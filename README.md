# 📊 Sudapac OS v1.1 — المنصة اللوجيستية الذكية وحوكمة الامتثال

منصة ذكية متكاملة ومصممة خصيصاً لـ **سوق اللوجيستيات وسلاسل الإمداد في المملكة العربية السعودية**، تعمل بفلسفة **"التحكم بالاستثناء" (Management by Exception)** لتأمين بوابات المستودعات، حوكمة الامتثال الحكومي والضريبي، وأتمتة العمليات ميدانياً عبر الذكاء الاصطناعي بنسبة 100%.

---

## 🚀 المزايا الاستراتيجية والوظيفية للمنصة

### 1. حوكمة الامتثال وبوابة النقل (TGA Broker)
* **التحقق من كروت التشغيل:** موديول ذكي يحاكي الربط مع بوابة "نقل" الرسمية التابعة للهيئة العامة للنقل للتحقق من صلاحية بطاقات تشغيل المركبات (نقل ثقيل/مقطورات) ونوعها قبل طباعة تصريح الدخول لمنع المخالفات والغرامات.
* **فحص هوية السائقين:** مطابقة أرقام الإقامات والهويات الوطنية التشغيلية آلياً عند البوابة.

### 2. التدقيق المالي الجنائي (ZATCA Compliance)
* **فك تشفير الـ QR (TLV):** قراءة مشفرة ومطابقة للحقول الخمسة الإلزامية الخاصة بهيئة الزكاة والضريبة والجمارك الفورية.
* **كشف الانحرافات والتباين (Variance Detection):** التحقق التلقائي من هيكلية الرقم الضريبي (15 خانة تبدأ وتنتهي بـ 3) ومطابقة نسبة الضريبة الرياضية للنسبة القانونية 15%، وقفل التشغيل فورا في حال رصد أي تباين.

### 3. خط الصوت وتحليل نبرة التوتر (Voice Telephony Pipeline)
* **تحويل الصوت لنص (STT):** استخدام نموذج `Faster-Whisper` محلياً لتفريغ مكالمات وملاحظات السائقين الميدانية وفهم اللهجات الدارجة.
* **استخراج البصمة النفسية:** معالجة فيزيائية للموجات الترددية عبر `Librosa` لقياس مستوى طاقة الصوت (RMS) لتحديد التوتر والغضب والتصعيد الآلي (Critical Escalation).

### 4. مركز التحكم المرئي (RTL Dashboard)
* لوحة تحكم ذكية ومؤشرات أداء (KPIs) حية مبنية بـ `Streamlit` وتدعم التخطيط العربي الكامل (Right-to-Left) لمراقبة وإدارة العمليات الميدانية والتدفقات اللحظية.

## 🛠️ بنية الملفات التشغيلية الموصى بها
```text
├── sudapac_app.py              # المحرك الرئيسي والمشغل للنظام
├── sudapac_ksa_broker.py       # موديول كروت التشغيل ووزارة النقل (TGA)
├── sudapac_invoice_backend.py  # موديول الامتثال الضريبي والفواتير (ZATCA)
├── sudapac_voice_pipeline.py   # موديول معالجة الصوت ونبرة التوتر
├── sudapac_dashboard.py        # واجهة لوحة التحكم الرسومية
└── requirements.txt            # المكتبات والاعتماديات التقنية
```

## ⚙️ طريقة التشغيل السريع
لتشغيل المحاكاة الفورية والسيناريو الميداني المتكامل على جهازك، نفذ الأوامر التالية:
```bash
pip install -r requirements.txt
python sudapac_app.py
```
